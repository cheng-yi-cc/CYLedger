## 预览与后续维护

本次手机预览：**CYLedger → 统计 → 月统计 → 点击年份**；**资产 → 人民币资金账户编辑 → 收益同步 → 输入 018607**；**资产 → 添加账户 → 加密货币交易所 → 币安 Binance → 搜索更多加密货币 → BNB**（选择标识 `binancecoin` 的结果；已有币安账户可从其“编辑账户”进入）。

买入单价预览：**资产 → 币安 Binance → 人民币买币**，选择“按付款金额”或“按买入数量”，填写买入单价即可看到另一项自动计算结果。

手动币种预览：**资产 → 钱包/交易所 → 编辑账户 → 搜索更多加密货币 → 找不到币种？手动添加**；添加新账户和录入已有持仓也可使用该入口。保存数量后进入币种详情的 **手动估值**，加密币默认每枚美元、可选人民币；当前不提供 USD24 自动行情，也不按固定 1 美元估值。美元价格按最新已公布汇率自动折算人民币，并显示实际汇率日期；缺汇率时保留美元价、人民币金额未知。

钱包品牌预览：**资产 → 添加账户 → 加密钱包**，选择 Bitget Wallet，或不选品牌直接填写名称与持仓。已有钱包进入 **编辑账户 → 取消品牌选择** 可恢复通用展示。

钱包货币与收支预览：**资产 → 钱包/交易所 → ⋮ → 编辑账户 → 货币单位 / 收支默认币种**；进入钱包详情的 **记支出 / 记收入**，或首页新增收支时在账户列表选择钱包。每笔实际币种数量均可修改，历史账单点开可修订或撤销。银行标志可在 **资产 → 银行卡** 查看，添加银行时也显示对应标志。

账户平铺预览：**首页 → 添加一条新记账 → 当前账户**，直接显示按资产页顺序排列的账户，可向下滚动或搜索，点击即选中。

已有功能：手机打开 **CYLedger → 首页 / 添加一条新记账 / 我的**。首页右上角“⋮”进入小卡片、模板、预算与截图导入；搜索在放大镜入口；备份及导入导出在“我的”。

电脑在主仓库 `D:\My Project\CY Finance Manager` 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Port 18080
```

打开 [手机布局](http://localhost:18080/mobile)。本机 8080 曾被其他应用占用，使用 18080；本命令使用主仓库原有的电脑账本，不与手机同步。需要从源码重建时添加 `-Build -DirectNpm`；首次登录和创建用户见 [运维说明](CYLEDGER_OPERATIONS.md)。Android 原生锁屏、文件管理和完整备份须在手机内预览。

账务边界与数据结构见 [架构](CYLEDGER_ARCHITECTURE.md)，接口见 [API 指南](CYLEDGER_API.md)，手机构建与签名见 [Android](../android/README.md)。
