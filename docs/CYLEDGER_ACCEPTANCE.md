# CYLedger 验收与交接

状态日期：2026-10-07。本轮在 `ba60` 工作区修改手机资产交互及共用账务逻辑，尚未合并或同步远端。按用户要求跳过审查建议第 9 点（货币基金账户模型），用户随后授权在已连接手机进行测试。真机操作使用独立 QA 包与虚构账本，正式账本仅做同签名覆盖升级与只读启动检查。

## 本轮已实现

- 搜索只筛选列表；顶部金额、收益、统计和资产首页统一采用持仓生效账本与账户规则。隐藏只改变可见性，不降低净资产；“不计入总资产”排除汇总，“盈亏不计入”使用成本计入净资产，并与市值区分。
- 新增理财先选所属账户，再填产品和持仓或成交；可录入已有持仓，也可一次提交新产品、首笔实际买入及资金扣款。基金手动记录不要求查询成功。
- 加密已有持仓支持人民币总成本及发生时间；转移区分总扣除、实际到账和同币手续费。历史兑换不以当前行情生成历史成本。
- 卖出默认录入实际到账，可使用全部份额，费用和结算币种明确；详情区分总成本与每份成本。
- 持仓编辑与账户编辑分开。累计收益显示偏差移至低频“对账修正”，标明仅影响显示，真实盈亏曲线不受影响。
- 列表聚焦名称、市值和收益，成本、数量及报价细节下沉详情；资产阅读页共用会话金额隐藏状态。公共接口分项加载，失败不丢弃其他成功数据。缺报价时空价格与涨跌幅显示未知；预置加密币不误标为未绑定行情。
- 真机发现并修复加密持仓编辑时动态样式覆盖路由页面状态的问题；基金样式改用独立属性，长成本字段允许换行，钱包校准流水只显示校准数量，不误写为兑换到 0 元。

## 未验证与外部依赖

- 本轮未重新验收备份恢复，未在正式账本上执行新增、修改或删除资金事实；第 9 点保持原样。
- 普通基金公开搜索、货币基金每日收益、加密现价和历史价格/汇率仍依赖供应商发布、网络及限额。本轮使用手动产品和隔离数据验证新流程，不将历史联网结果当作本轮联网验收。
- 新增买入要求已确认份额；未确认基金申购仍使用原有待确认指令流程。未知成本、价格和汇率继续显示未知。
- 显示修正不影响真实历史收益；年化仍为原有资金占用日简单估算。加密定投不向交易所下单，手机和电脑账本独立。
