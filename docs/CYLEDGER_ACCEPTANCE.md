- 标签管理使用一级卡片与子标签，支持增改、隐藏、删除、排序、分组和查看账单。分类直接切换支出/收入/转账，展开管理二级分类，保留图标、颜色、生效账本与原有删除约束。排序取消不改变已保存顺序。

- 保留既有多账本、预算、投资、基金及加密定投、货币基金收益、报销、债务和备份功能。完整能力与边界见 [产品范围](CYLEDGER_BRIEF.md) 和 [使用入口](../README.CYLEDGER.md)。

## 本地预览

手机：**CYLedger → 我的 → 标签管理 / 分类管理**；**统计 → 月统计 → 资产走势**。

电脑在主目录运行以下命令，再打开 [手机布局预览](http://localhost:18083/mobile)：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Port 18083
```

从源码重建加 `-Build -DirectNpm`。首次创建电脑账户见 [运维说明](CYLEDGER_OPERATIONS.md)。接口见 [API 指南](CYLEDGER_API.md)，内部机制见 [架构](CYLEDGER_ARCHITECTURE.md)，签名和真机升级见 [Android 说明](../android/README.md)。
