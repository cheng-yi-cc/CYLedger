## 未覆盖及外部依赖

- 共享成员及成员收支按本次确认不实现。手机与电脑自动同步、多设备离线合并、交易所下单、税务及端到端加密未实现。
- 历史资产走势依赖已保存的估值快照，缺失或失效处保留断点；外币账单没有历史汇率依据时，不使用今日汇率回填。
- 基金、证券、加密资产公开行情与汇率依赖网络及供应商；统计、标签、预算和总结本身无需新增外部密钥。
- 未覆盖长期后台运行、自然跨日等待、所有附件流程、其他机型和系统版本；通知到时送达未做跨日实测。
- Docker 容器、公网 HTTPS 和真实一木文件迁移未在本次验收中执行。

## 预览与后续维护

手机打开 **CYLedger → 统计**。预算入口为 **日常 → 预算占比 → 查看详情**，也可从统计右上角菜单进入；标签层级在 **我的 → 标签管理** 设置，普通收支编辑页可填写优惠。

电脑在主仓库目录 `D:\My Project\CY Finance Manager` 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Port 18080
```

打开 [手机布局](http://localhost:18080/mobile)。本机 8080 被其他应用占用，使用 18080；上述命令启动主仓库自己的运行目录，首次登录和创建用户见 [运维说明](CYLEDGER_OPERATIONS.md)。修改源码后启动命令加 `-Build -DirectNpm`。手机与电脑账本独立。

账务边界与数据结构见 [架构](CYLEDGER_ARCHITECTURE.md)，接口见 [API 指南](CYLEDGER_API.md)，手机构建与签名见 [Android](../android/README.md)。后续维护按变更范围更新本页当前状态。
