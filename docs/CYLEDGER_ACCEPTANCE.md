## 真实行情与外部依赖

本机已验证 Coinbase **Advanced Trade 公共 WebSocket** 自动报价，以及 `ECB via Frankfurter` 的 USD/CNY 参考汇率。实现使用 `wss://advanced-trade-ws.coinbase.com`，不是未经验证地照搬需求文档中的 Exchange 地址。BTC、ETH、SOL、USDT 的支持以查询到的真实产品映射为依据。

留存的 ETH 接口样本标记 `source=Coinbase WebSocket`、`state=live`、`connected=true`；汇率样本标记 `fxSource=ECB via Frankfurter`、`fxDate=2026-09-18`、`fxState=delayed`。币价时刻与汇率参考日期分开保存；周末取得最近工作日汇率不意味着汇率刚刚更新。

CoinGecko 备用接口已实现，但本机没有配置 `CYLEDGER_COINGECKO_DEMO_API_KEY`，因此**真实 CoinGecko 请求没有验收**。其鉴权、批量解析和调用预算有本地 Mock 测试，不能据此声称线上密钥可用。默认 15 分钟批量备用，浏览器轮询本服务缓存不会按相同频率请求 CoinGecko。

USDC 没有经本轮确认的 Coinbase 美元交易对。缺少备用源报价时明确显示无法自动估值，可以手动填写价格；没有将其硬编码为 1 USD。股票、基金和私人资产初版采用手动估值，不承诺自动行情覆盖。

## 使用入口与账号

本次交付的个人实例已在 **http://localhost:8080/** 运行，可以直接打开。若 8080 已有本应用运行，不要重复启动；仅在服务停止后，从项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1
```

需要从源码重新构建时，先停止现有服务，再执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Build -DirectNpm
```

这两条命令对应脚本的真实参数，默认端口为 8080。`-DirectNpm` 只使用本次构建的独立 npm 用户配置。脚本另外支持 `-Port`、`-BindAddress`、`-RuntimeDirectory` 和 `-ConfigureOnly`。没有 `-Background` 或一键 Docker 恢复参数；后台运行需要按实际操作单独安排。

公开注册保持关闭。本次本机实例的登录用户名为 `cyledger`，密码仅保存在私密运行文件 `.runtime/LOCAL_LOGIN.txt`，本报告不读取或复制其内容。这个账户只为本次本机交付创建，不是通用安装的默认账号或默认密码；在其他机器新安装时，按 [运维说明](CYLEDGER_OPERATIONS.md#创建自己的登录账户) 运行交互式 `create_user.py`。

个人实例与验收数据库分开。18080、18082 验收服务已停止，过程目录、日志和截图保留。完整部署、日志、备份、恢复与升级命令见 [运维说明](CYLEDGER_OPERATIONS.md)。
