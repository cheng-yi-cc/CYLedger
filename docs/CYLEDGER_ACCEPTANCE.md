# CYLedger 验收与交接

状态及最新手机验收日期：2026-10-06。本轮重做手机「资产 → 理财」及其新增、持仓详情、买卖、编辑、管理、统计与定投页面，参考手机中已安装的一木记账 6.6.8 的信息层级和操作方式，保留加密资产流程。所有新增、修订、撤销及删除测试均使用独立 QA 应用的虚构账本；参考应用只作观察。

## 当前交付

- 理财首页显示总资产、累计收益、按类别折叠的持仓列表；顶部提供统计、搜索与新增，底部提供清仓记录、定投和管理。
- 新增基金进一步按参考应用逐项还原字段顺序、左对齐输入、字体、卡片间距、关闭/勾选按钮、开关、分组底部弹窗及账本居中弹窗；输入完整六位代码自动补名称，按名称选择后回填代码，保存后返回理财列表。
- 持仓详情集中显示金额、今日/持有/累计收益、成本价、份额与最新价，直接买入、卖出；流水详情、导出、编辑、手动报价、账户间转移及隐藏在对应入口。浅色、深色使用现有主题。
- 支持基金、货币基金、证券、期货贵金属及自定义理财，保留加密钱包、交易所及实际币种收支。货币基金复用资金账户与原有逐日收益服务，理财页展示其本金和已记录收益，不重复增加净资产。
- 新增/编辑支持盈亏偏差、分组、备注、隐藏、是否计入总资产与收益、账本可见范围。期初持仓原子创建；修改数量和成本生成可撤销的校准记录，只改名称等展示字段不改成本。
- 基金支持按份额/净值或付款金额/费率录入，保存交易日期、确认日期和净值来源。未取得净值时进入待确认列表；确认前不扣现金、不增份额，可以取消或手工确认。
- 基金定投支持每日、每周、隔周、每月、起止日期、时间、付款账户、金额、费率及暂停/删除。打开应用及前台运行时检查到期记录，按已公布历史净值确认；余额不足或缺净值保持待确认。每期永久防重，已确认记录撤销后不会自动补记同一期。
- 统计提供买入、卖出、净投入、费用、已实现收益、累计盈亏及有依据时的估算年化；历史走势仅使用已保存的估值快照，不补造历史价格。货币基金本金和已入账收益纳入当前汇总，其现金流水不混入持仓交易统计。
- 既有日常记账、多账本、报销、债务、统计预算、导入导出、钱包货币单位、银行标志和完整备份继续保留。入口见 [使用与开发说明](../README.CYLEDGER.md)，账务约束见 [架构](CYLEDGER_ARCHITECTURE.md)。

## 实现范围与外部依赖

- 定投已经实现到期检查和补记，但没有新增应用完全关闭时的系统定时唤醒。打开应用或前台运行会继续处理到期任务；暂停/删除计划停止后续自动确认，删除保留永久防重标记。
- 自动确认使用已公布历史净值并按费用与份额规则估算，可能与交易平台实际成交不同；用户已接受该误差。系统不向交易平台下单，实际确认可在待确认或对应流水中修订。
- 基金、证券、加密资产和汇率依赖公开数据源网络，本轮没有新增必须配置的密钥。缺净值、价格或汇率保持待确认/未知，不承诺所有 VPN 和数据源持续可达。
- 盈亏偏差只调整展示，不生成现金；估算年化不等同于 XIRR，不具备充分成本/历史依据时不计算。历史走势依赖有效估值快照。
- 仅覆盖本机主要竖屏流程，未覆盖其他 Android 版本、平板、横屏与长期后台运行。系统验证仅有先前唤起/取消记录，指纹、面容或 PIN 成功解锁须机主操作。
- 既有范围仍不含登录入口、云同步、普通账单自动识别记账、扫一扫、AI/语音记账、多设备离线合并、交易所下单和税务。基金定投与货币基金收益为明确支持的自动记录功能。
- CSV 用于查看和交换流水；完整还原关联与附件须使用数据备份。手机 ZIP 备份未加密，与电脑备份格式不同。本轮没有执行 Docker、公网部署或真实一木账本文件迁移。

## 预览与维护

手机打开 **CYLedger → 资产 → 理财**。右上角「新增 → 基金」可输入完整代码自动补名称，再按页面顺序填写并点右上角勾号保存；点入持仓查看详情和买卖；页面底部「理财定投」管理计划与待确认记录，统计入口在顶部。货币基金沿用对应资金账户的收益同步；加密资产继续使用钱包/交易所的币种流程。

电脑在主目录 `D:\My Project\CY Finance Manager` 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Port 18082
```

打开 [手机布局](http://localhost:18082/mobile)，登录后进入「资产 → 理财」。本轮已生成前端和 Windows 后端，通常无需重建；从源码重建时加 `-Build -DirectNpm`。18082 用于避免与原有本地服务冲突；本命令使用主目录原有电脑账本，不与手机同步。首次使用见 [运维说明](CYLEDGER_OPERATIONS.md)。原生文件选择器、锁屏和完整备份须在手机验收。

接口见 [API 指南](CYLEDGER_API.md)，数据模型与历史快照规则见 [架构](CYLEDGER_ARCHITECTURE.md)，Android 构建与签名见 [Android 说明](../android/README.md)。
