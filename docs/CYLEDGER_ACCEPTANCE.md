# CYLedger 验收与交接

状态日期：2026-10-07。交付范围包括手机资产管理、投资账务交互，以及同日主分支的分类/标签管理与资产走势更新。按确认范围保持货币基金账户模型不变。正式账本仅做同签名覆盖升级与只读检查；写入验收使用独立 QA 包和虚构数据。

## 已实现

- 资产搜索只筛选列表；列表、顶部金额与统计共用账本和账户范围。隐藏仍计入汇总，“不计入总资产”才排除，“盈亏不计入”按成本计入净资产，同时保留真实市值。
- 新增理财按“账户 → 产品 → 持仓或成交”填写。已有持仓不扣资金；新产品、首笔已确认买入与现金扣款原子保存。基金可手动记录，无需查询成功。
- 加密已有持仓支持人民币总成本与发生日期；转移区分总扣除、实际到账和同币手续费。卖出支持实际到账及全部份额。持仓校准与账户编辑分开，累计收益显示修正不改变真实盈亏。
- 资产阅读页共用金额隐藏状态；详情显示总成本、每份成本及报价来源。公共接口分项加载，失败保留成功数据；缺报价保持未知。加密持仓编辑保存/取消可正常返回，校准流水不误写成兑换。
- “我的”六个常用入口每行三个；分类与两级标签使用层级卡片，支持增改、隐藏、分组、删除及排序草稿。资产走势图共用普通/放大视图，保留单点与未知断点，随主题切换。
