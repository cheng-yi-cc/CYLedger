# CYLedger 产品范围

CYLedger 面向个人手动记账，将日常资金、负债、报销和投资持仓放在统一资产视图中。本文是当前产品约束；具体实现见 [架构](CYLEDGER_ARCHITECTURE.md)，使用方法见 [使用入口](../README.CYLEDGER.md)，验证范围见 [验收与交接](CYLEDGER_ACCEPTANCE.md)。

## 技术与形态

- 基于 ezBookkeeping v2.0.0 二次开发，复用 Go、Vue、Framework7、Vuetify、Pinia 和 SQLite，保留原模块路径与上游许可。
- 手机优先，提供网页/PWA 和独立 ARM64 Android 应用；默认简体中文、人民币本位，会计时区由用户设置。
- Android 内置后端与数据库，电脑部署使用独立实例。两端没有自动数据同步，不把 PWA 缓存能力等同于完整离线合并。
- 个人自用优先，不做资金托管、下单、转币、交易所账户同步或通知读取式自动记账。

## 现有产品能力

| 范围 | 能力 |
|---|---|
| 日常账务 | 收支、转账、分类/子分类、标签、模板、附件、查询编辑、CSV 导入导出 |
| 多账本 | 默认、排序、归档、组合筛选、流水移动和分类范围；账户余额在用户内共用 |
| 资产管理 | 资金、信贷、预付、保险、二手资产、债务、报销及投资账户；分组、隐藏、资产统计选择和余额校准 |
| 报销与债务 | 分次到账、结束/恢复/取消报销；借入/借出、还款/收回、本金和利息关联 |
| 信用卡与定存 | 账期、还款规则、共享额度、年费条件、分期；定存预计收益、到期收益及提前结束 |
| 投资 | 期初、买入、卖出、币币兑换、同币转移、手续费、未知成本、历史修订与撤销 |
| 行情 | 显式绑定公开证券/基金/加密参考价，人民币汇率，手动估值，过期/缺失状态 |
| 自动收益 | 人民币账户显式绑定货币基金后逐日结算，缺失收益等待，历史记录防重 |
| 日历与统计 | 收支日历、农历/节气、手动到期事项、资产提醒、分类与日期统计、资产快照 |
| 数据运维 | SQLite 完整备份、校验、空目录恢复；Android 同签名覆盖升级 |

界面参考用户提供的应用行为独立实现，不复制其代码、资源或个人壁纸。浅色、深色和跟随系统均保留。

## 账务口径

1. **事实、成本和估值分层。** 成交和现金流水属于事实；持仓数量与移动加权成本可重放；行情只改变估值。货币基金自动收益是用户明确开启的独立入账流程。
2. **不重复计算。** 内部转账、投资买卖结算与债务本金不作为日常收支；分期不重复记本金；定存本金仍属于原账户。系统投资结算账户不属于真实资产。
3. **未知就是未知。** 期初成本、价格或历史汇率不足时保留未知，不能拿零、稳定币固定汇率或当前汇率补造。
4. **精度不靠显示值。** 新增接口金额、数量、价格和汇率使用十进制字符串；数量/价格支持 18 位小数，成本除法使用 36 位精度，资金流水按原有分单位落账。
5. **一次操作全部成功。** 相关资金、事件、关联和防重记录在同一数据库事务内提交；超卖、过额报销、并发余额变化及跨用户请求失败时不部分落账。
6. **历史可追溯。** 修订/撤销重新回放受影响历史并使快照失效；历史快照仅使用当时保存的价格。删除自动收益流水后不再次生成。

移动加权成本按“用户 × 投资账户 × 资产”计算。卖出释放对应比例成本，全仓卖出释放全部尾差；无手续费转移携带历史成本。费用不能在取得成本和盈亏里扣两次。该口径用于个人资产分析，不作为税务申报结果。

## 范围之外

尚未实现手机/电脑同步、多设备离线合并、手机完整备份入口、持续后台计算保证、个人单日投资收益、链上扫描、合约/DeFi/NFT、税务、多人协作和端到端加密。房产、车辆与保险按手动余额管理；自动年费扣款、银行扣款及实际还款不由计划代为执行。

通用 CSV 映射能力保留；尚无真实一木导出样本的专用迁移验收。Docker 配置已交付，但没有完成当前版本容器运行验收。外部行情、汇率和 Android 通知分别依赖网络/供应商及系统权限。
