# 行情网络：国内直连、海外中转、独立刷新

## 路由与调度

早期实现让基金、证券和加密资产搜索持同一把锁等待网络；主分支已缩小锁范围，本次合并进一步加入请求合并与有界并发。原基金公共 DNS、逐 IP 重试与慢连接竞速由独立路由替代。

现在保留现有账本、估值和十进制计算，只重构公开行情传输与调度：

```text
手机 / 电脑的 Go 行情服务
  ├─ 独立国内连接池 → 天天基金 / 腾讯财经
  ├─ 独立海外连接池 → Coinbase / CoinGecko / Bitstamp / Frankfurter（未配置中转）
  └─ 国内连接池 → 自建 HTTPS 行情中转 → 上述海外接口（配置中转后）
                  └─ WSS → Coinbase 实时行情
```

中转不接收账本、持仓、余额、成本、账户令牌或交易指令，只接受白名单公开行情路径和公开标的。中转运营者仍能看到公开标的、请求时间和客户端 IP；这不是匿名服务。

## 网络边界

Windows/Linux/macOS 的“直连”表示此连接池不使用 HTTP(S) 环境代理。它**不能**绕过系统 TUN/全局 VPN 路由。保留 VPN 时，需要在 VPN 客户端把国内来源及中转域名设为直连；不要为了行情修改全局系统代理。

Android 监听可用的非 VPN 网络，对国内行情和自建中转的连接单独绑定物理网络，并在同一网络解析 DNS，避免把 VPN 的 fake-IP 带到 Wi-Fi。只绑定这些 socket，不绑定整个进程；VPN 开关、Wi-Fi/蜂窝变化会清理闲置连接，旧报价不被清空。

**VPN 可以禁止旁路，系统“禁止无 VPN 连接”也可能阻止物理网络连接。** 这种情况下代码遵守系统规则并回退，不能保证开着任意全局 VPN 都直连成功。可在 VPN 中配置来源/中转分流；或在配置可达中转后关闭 VPN。中转必须从使用地实测可达；部署到海外不等于国内一定可达、低延迟。

未配置中转时保留原来的海外源访问方式。未部署服务器、域名和 HTTPS 前，不能宣称已经实现“免 VPN”。DNS 优化、缓存与并发无法创造一条不存在的海外出口。

## 调度、时效和开销

- 相同搜索合并；单个调用方取消不影响另一调用方；不同市场不再持全局锁等待。每条搜索通道最多 4 个共享任务，整个任务含排队最多 4 秒。缓存命中直接返回，不进等待队列。
- 跨来源同时查询；一个来源有非空结果后最多再给其他来源 300 毫秒。部分成功可以返回，但不会冒充完整结果缓存。完整目录缓存 10 分钟，最多 200 项。
- 腾讯、基金、Coinbase 的注册标的各自独立刷新，每来源最多 4 个批次并发。新标的唤醒对应刷新循环；基金成功后前台按 5 分钟、空闲按 30 分钟预算刷新，失败约 1 分钟后允许重试，前台活跃期结束不延长失败重试间隔。未开始的取消任务不消耗刷新预算。
- HTTP 总请求预算默认 8 秒，连接和 TLS 各 3 秒，响应头 4 秒，这些预算不是实际测速或保证延迟。不同来源使用隔离连接池并复用连接。
- Coinbase 连接实时流前不再逐资产串行等待 REST；断线保留原来的重连/REST 回退。CoinGecko 前台每分钟最多一批、空闲至少间隔 15 分钟，失败与限流也计入预算。

**时效不等于加载速度。** 基金净值和万份收益只展示来源已公布的数据，不能变成秒级实时净值；中转不修改价格的来源时间。旧价格继续标记过期，缺失不补零，不拿稳定币固定汇率充行情。公共接口不提供可用性或覆盖保证。

前台估值页面通常每 5 秒读取本地共享缓存，仍受页面状态、网络与汇总计算耗时影响。后端 Coinbase 使用实时流；前端沿用汇总轮询。中转目前每个客户端一条 Coinbase 流，不是多租户共享订阅服务。

今日收益的 Coinbase Advanced / Exchange 分钟线、CoinGecko OHLC、带日期的 ECB 汇率，以及加密定投的 Bitstamp 分钟价与 ECB 历史汇率均接入白名单中转。请求保留精确分钟、截止日期与十进制精度，成本和收益算法不变；缺少历史数据仍保持未知或待处理。

## 部署海外行情中转

使用具备海外源访问能力、且客户端可直达的自有服务器。在项目根目录构建：

```sh
go build -trimpath -o cyledger-market-relay ./tools/market-relay
```

在服务器私有环境文件中配置（令牌应使用至少 32 个随机字符，不要提交）：

```sh
MARKET_RELAY_LISTEN=127.0.0.1:8787
MARKET_RELAY_TOKEN=<仅用于此行情服务的随机令牌>
# 可选，由服务器保管，不发给客户端：
CYLEDGER_COINGECKO_DEMO_API_KEY=<你自己的 Demo API key>
```

通过服务管理器启动，前面使用已有 Caddy/Nginx 提供 HTTPS。Caddy 配置示例见 `deploy/market-relay/Caddyfile.example`，systemd 示例见同目录。需要自己的域名、正确 DNS、证书与外部 443 端口；不直接把 8787 暴露公网。不得复用交易所密钥、账本密码或其他管理令牌。遵守各来源使用条件、所在地区规定和账户额度。

中转仅允许 GET、固定公开 HTTPS 上游和受限查询字段；不允许任意 URL、CONNECT、账户/交易接口及重定向。HTTP 响应大小上限 4 MiB；缓存最多 128 项、单项 128 KiB；HTTP 等待请求最多 12 个，WebSocket 最多 16 个；超限返回 429。上游错误不缓存，旧报价由客户端保留。缓存不改供应商时间。

这是小规模自用中转。公开发布前须增加反向代理层访问限制/速率控制、监控和令牌轮换；并发上限不等于严格每分钟调用额度。APK 内配置可被提取，令牌只能视为可撤销的低权限公开行情访问凭证，不是客户端秘密。不要把带自用令牌的 APK 发给不受信任的人。

## 客户端配置与预览

电脑端在启动 CYLedger 的同一个 PowerShell 会话设置：

```powershell
$env:CYLEDGER_MARKET_RELAY_URL = 'https://quotes.example.com'
$env:CYLEDGER_MARKET_RELAY_TOKEN = '<与中转一致的行情令牌>'
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Port 18083 -Build -DirectNpm
```

浏览器打开 `http://localhost:18083/mobile`，进入投资资产搜索/列表及货币基金绑定页。仅配置环境变量后必须重启已有后端；URL 是 HTTPS origin，不含路径、用户名或查询参数。只有字面量回环 IP 可用 HTTP，供测试使用。

Android 把配置放在**仓库外**的私有 JSON 文件，然后构建独立 QA 版：

```json
{"relayUrl":"https://quotes.example.com","relayToken":"<与中转一致的行情令牌>"}
```

```powershell
python scripts/build_android.py --qa --market-network 'D:\private\market-network.json'
```

构建把配置放入应用 assets，再复制到应用私有目录；不经过前端、不进入账本备份允许列表。配置参与资源版本摘要，因此覆盖升级会更新它；不传 `--market-network` 会恢复默认直接访问海外源的行为。配置错误不能阻止离线账本启动，后端只记录不含配置内容的通用提示。正式升级沿用已有签名，使用 `adb install -r`，不得卸载或清数据。

## 验证与当前外部依赖

自动回归涵盖来源隔离、凭据边界、同查询取消/合并、慢加密源不阻塞基金、部分目录不被缓存、并发上限、中转白名单和错误缓存；继续运行旧报价/净值/收益/汇率测试。合并检查增加真实调用链经过本地模拟中转的今日收益三种报价路径、定投分钟价与历史汇率、高精度现价，以及基金失败跨前台活跃期的重试。已通过的本机检查见 [验收与交接](CYLEDGER_ACCEPTANCE.md)。

真实验收须在独立 QA 账本执行 VPN 关闭、系统代理开启、TUN 开启、VPN 禁止旁路、Wi-Fi/蜂窝切换及上游超时/429 场景；记录冷/热查询耗时、来源时间、过期状态和请求次数。网络错误时不得改变持仓或把金额归零。普通业务备份/正式账本不能用于破坏性测试。

当前已构建独立 QA APK，未部署中转、配置生产域名/令牌或进行真实网络测速。合并时没有连接手机，未完成新版本真机安装和正式版覆盖升级；现有正式 APK 与手机版本保持此前验收基线。完成部署及网络验收后才能给出实际端到端延迟结论。
