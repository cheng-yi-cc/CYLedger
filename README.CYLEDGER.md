# CYLedger 使用与开发入口

项目概览和安装入口见 [README](README.md)，部署、登录及完整备份见 [运维说明](docs/CYLEDGER_OPERATIONS.md)。Android 与电脑账本相互独立。

## 从空账本开始

1. 在“资产 → ＋”建立银行卡、现金或支付账户。仅从启用日开始记账时填当前余额；导入历史流水时填对应的历史起始余额，避免重复累计。
2. 在“我的 → 账本管理”创建账本。流水、模板和分类可按账本管理，资金账户在各账本间共用；移动流水不会再扣款，归档账本只供查询。
3. 使用中间记账按钮录入支出、收入、转账或债务。分类、标签、备注、日期、附件和四则金额键盘在同一流程中使用；“再记”保存后继续下一笔。
4. 在“资产 → ＋”建立证券、加密交易所或钱包。录入已有持仓不扣资金账户；新买入才记录实际支付。成本不清楚可留空，未知成本不会按零计算盈利。

## 首页、记账与我的

手机默认使用干净浅色主题。首页可搜索账单、用 `#标签 空格` 精确匹配标签，组合日期、金额、备注、地点、账本、账户、报销、分类、标签及附加条件；支持历史记录、金额排序、多选移动/删除、CSV 或 Excel 导出、图片账单。右上角菜单提供数据小卡片、模板、预算、简洁/详细显示、全部/月度范围以及微信/支付宝截图导入。

记账页集中显示分类、标签、备注、四则键盘，以及日期、账户、报销、附件、优惠、属性。优惠按原价/优惠/实付计算；转账手续费正数为支出、负数为优惠收入，和转账一起保存、修改、删除。借入/借出可填写约定还款日期，在日历生成关联事项；提醒不自动记还款。地点可填文字，也可申请系统定位权限。

“我的”提供本机昵称/头像、周期记账、愿望清单、分类关键词、账本/标签/分类管理、更多设置、完整备份、导入导出、账单图片与主题。愿望的手动储蓄或计划进度不修改账户余额；分类关键词只为导入预览匹配已有分类、账户和标签。

数据卡片可选择内容、统计周期、账本/账户/分类/标签范围、大小、颜色、背景照片和透明度并排序。预算复用实际账务口径；待报销显示尚未到账金额。黄金卡片展示已绑定的黄金标的报价；历史资产走势需要已有有效快照。缺少换算或报价保持未知。

导入支持原有文件解析器、CSV/Excel 字段映射和本机离线截图识别。识别结果须核对账户、分类、金额和时间后确认，疑似重复默认不选；缺失日期暂填识别当天，缺失时间暂填 12:00。每次导入作为一批保存，可在导入记录中整体撤回。CSV/Excel 是账单交换文件；完整还原优惠、手续费关联、附件和其他业务须使用完整备份。

本机版按约定不提供登录入口、云同步、第三方账单自动采集、扫一扫、AI 截图记账、文字智能记账或语音识别；保留普通文件和离线截图导入。显式设置的周期计划、基金收益与加密定投按各自规则处理。

## 资产入口

| 入口 | 操作与口径 |
|---|---|
| 资产首页 | 净资产、资产/负债、报销/债务/理财摘要、分组折叠、金额隐藏、账户排序与隐藏 |
| 新建/编辑账户 | 资金、信贷、预付卡、保险、房产/车辆、自定义、债务、报销及投资账户；简称、备注、卡号、图标、分组、生效账本和计入总资产 |
| 资金账户详情 | 记账、转账、余额校准、余额变动、资产明细、转账记录、流水对账、CSV 导出、定期存款及编辑/删除 |
| 收益同步 | 从人民币资金账户编辑页进入；只填基金名称、代码、开始计息时间，名称/代码均可搜索；解绑保留历史收益 |
| 报销 | 创建报销账户，记支出时选择报销对象；在待报账单记录一次或多次到账，可结束/恢复或取消报销 |
| 债务 | 追加借入/借出、分次还款/收回、利息/优惠、还款日期、方向转换和结清隐藏；本金不重复计入收支 |
| 信用卡 | 额度/共享额度、账单日、还款规则、年费条件、各期账单、还款记录及分期管理 |
| 定期存款 | 记录已在账户内的本金、利率、期限、开始日期，查看预计收益、到期结算或提前结束 |
| 投资与加密账户 | 股票、基金、加密资产和其他持仓；买入、卖出、币币兑换、账户转移、历史修订及撤销 |

长按账户或使用详情菜单可删除。先查看关联记录预览，再选择处理关联交易或确认级联删除。转账双边、投资事实和其他账户余额会一起校验、更新；剩余投资历史不成立时整次取消。系统结算账户不能删除。

余额校准保留差额流水，可选是否计入收支。房产、车辆、保险、预付卡沿用账户余额，不提供市场自动估价。信用卡分期不重复增加本金负债；费用按计划独立入账，实际还款须另行记录。

货币基金仅对显式绑定的账户生成收益，按账内交易和起息规则计算；这不等于银行或基金平台实际结算。定存本金不再次增加资产，并从其有效期内的货币基金计息本金扣除。普通证券/加密行情只改变参考估值。

### 加密货币每日定投

从“资产 → 加密货币交易所账户 → 每日定投”添加计划；电脑投资工作区也提供“每日定投”标签。支持用定量 USDT 或 USDC 每日买入 BTC、ETH、SOL，分别填写投入数量、时间、开始日期和账本，时区使用用户当前设置并保存到计划。

这是与交易所计划对应的本地参考记账：不连接交易所账户、不提交订单。应用运行时检查到期安排；关闭后重新打开，按指定分钟的历史公开价格补记，缺少历史价格或人民币汇率则保留待处理。稳定币和买入币均读取实际公开价格，不把稳定币固定为 1 美元；手续费默认为 0，实际成交有差异时可修订投资流水。

扣款从所选交易所已有的稳定币持仓中发生，并和买入、成本、防重记录一起原子保存。不足一次扣款时直接暂停，不生成买入；补足后须手动恢复，从下次计划时间继续，暂停期间不补买。多个计划共用同一稳定币时，按合计未来三天用量弹窗提醒，每个会话每天去重。

计划显示累计投入、累计买入及人民币买入成本；成本与收益详情显示该账户同币种合并后的剩余成本、平均成本和未实现盈亏。人工撤销不会让同一天再次自动买入。调整计划只影响后续安排，原有待处理安排停止，已入账事实保留。

### 账户单位与选择

添加加密钱包时，钱包品牌为可选项：可选择 Bitget Wallet 等品牌，也可只填写账户名称、选择币种并录入已有数量。不选品牌使用通用钱包图标；编辑账户时可取消品牌选择，名称与持仓保持原样。Bitget Wallet 与 Bitget 交易所是不同选项。

钱包/交易所的“编辑账户 → 货币单位”可随时选择人民币或美元，账户市值和新增收支默认跟随，总资产仍按人民币汇总，旧账单保留原币金额与当时汇率。在“收支默认币种”设置优先扣款/默认收款币种及备用支出币种，例如 USD24 优先、USDC 补足。账户详情的“记支出 / 记收入”可直接使用；首页普通收支的账户选择也包含钱包。默认按每枚约 1 美元估算数量，保存前可按实际交易修改；这不会把市场报价固定为 1 美元。人民币录入用参考美元汇率估算数量，缺失汇率或历史日期需填写实际数量。收支保存、修订和撤销同步更新持仓、分类账单与人民币统计，避免重复增加或扣减资产。

普通资金账户仅在零余额且无历史及计价规则时可修改货币单位，已有余额或流水的账户保持原币种。银行卡与信用卡按名称或常见简称自动显示银行标志，覆盖工行、农行、中行、建行、交行、邮储、招行等 19 家；自上传图标保留，无法唯一识别时使用原图标。

新增记账选择账户时，按资产页顺序直接平铺所有可选账户，保留图标、余额和搜索，点击即可选中，无需先选择账户分类。支出、收入与转账使用一致的列表；账户隐藏、账本范围及各记账类型的可用限制继续生效。

## 日历、统计与提醒

日历按用户时区、每周起始日显示收支、农历/节气、手动事项和到期安排；选中日期可直接记账。事项自身不改余额。

统计提供“日常 / 月统计 / 年统计 / 自定义”四个入口，支持多账本和账户/分类/标签筛选、展开收支摘要、柱线切换与放大、历史资产走势、收支对比、分类/账户/标签占比、分类同期比较、可排序报表与账单下钻、年度热力图及月年总结。右上角菜单可分别调整四种周期的模块显示与顺序，复制或导出消费分析文本。

日常统计的“预算占比 → 查看详情”进入月预算、分类预算和自定义预算；可设置后续沿用、余款/超支结转、日均预算及进度条口径。预算由实际支出重算，不维护另一份账户余额；内部转账、投资结算、报销和不计统计的账单排除，退款冲减消耗。外币缺少历史汇率时保持未知。

标签支持两级，在标签管理或新建标签时选择上级；统计可选择所有标签、一级含子级、一级不含子级或二级，按一级含子级汇总时同一账单不会重复计数。普通收支记账可填写优惠金额；账单金额仍为实际支付/到账，优惠不会再次改余额。共享成员不在当前单人版范围内。

资产提醒可组合信用卡、借款日期、手动事项及定存到期。Android 通知需要系统授权；应用被停止期间不保证持续计算，重新打开时补齐可结算记录。

## 行情与未知值

搜索后核对市场、代码、来源和币种再绑定。同名资产不自动合并；手动价格优先。证券、基金、加密报价和人民币汇率保留各自日期与状态，缺失值不按零处理，报价过期会明确标记。

手机端搜索不到的币种，可从“搜索更多加密货币 → 找不到币种？手动添加”填写名称与代码，再录入持有数量。保存后进入币种详情的“手动估值”，加密货币默认填写每枚美元价格，也可切换人民币；股票、基金等仍填写人民币价格。美元原价会保留，人民币市值按最新已公布的美元汇率自动折算，并显示汇率来源与实际日期；原有人民币报价仍按人民币解释，缺报价或汇率时人民币估值保持未知。手动报价只改变估值，不改变数量、成本或资金流水，也不会自动将同名币种合并。比如 Arbitrum 合约 `0xbE00f3db78688d9704BCb4e0a827aea3a9Cc0D62` 对应 [Fiat24 USD（USD24）](https://docs.fiat24.com/developer/integration-guide/part-1-smart-contracts)，不应当成 USDT 添加或套用 USDT 行情。

人民币买币可选“按付款金额”或“按买入数量”，买入单价由用户填写：付款金额除以单价得到数量，数量乘以单价得到付款金额；人民币四舍五入到分，输入的买入数量保持不变。此流程无需参考行情，扣款和持仓仍原子保存。币币兑换与卖币的行情换算只供参考，实际支付/到账由用户确认；缺少历史换算依据的成本和盈亏保持未知。供应商、刷新规则、可选密钥及联网检查见 [行情模块](pkg/marketquotes/README.md)。

## 本机开发

现有工具：Go `D:\tools\cyledger\go\bin`、GCC `D:\tools\cyledger\mingw64\bin`，启动脚本会将它们加入当前进程 PATH；需要 Node.js/npm 和 Python。Android 工具路径与构建命令见 [Android 说明](android/README.md)。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Build -DirectNpm
```

浏览器打开 [http://localhost:8080/mobile](http://localhost:8080/mobile)。`-DirectNpm` 使用独立 npm 配置，不修改全局代理。正式运行数据在 `.runtime/data`、附件在 `.runtime/storage`；签名配置、已有本机登录说明和 Android 签名材料均为私密文件，不提交仓库。

按改动范围执行必要检查：

```powershell
go test ./pkg/investments ./pkg/monetaryincome ./pkg/marketquotes ./pkg/services ./pkg/models ./pkg/api ./android/backend
node node_modules/vue-tsc/bin/vue-tsc.js --noEmit
node node_modules/vitest/vitest.mjs run
npm run build
python -m unittest discover -s scripts -p test_backup.py -v
```

涉及手机流程时，还需独立 QA 包的真机验收和同签名正式版覆盖升级。已执行的检查与没有覆盖的部分统一记录在 [验收与交接](docs/CYLEDGER_ACCEPTANCE.md)，不以编译通过代替账务或真机验证。
