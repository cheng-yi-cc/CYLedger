# CYLedger 使用与开发入口

项目概览和安装入口见 [README](README.md)，部署、登录及完整备份见 [运维说明](docs/CYLEDGER_OPERATIONS.md)。Android 与电脑账本相互独立。

## 从空账本开始

1. 在“资产 → ＋”建立银行卡、现金或支付账户。仅从启用日开始记账时填当前余额；导入历史流水时填对应的历史起始余额，避免重复累计。
2. 在“我的 → 账本管理”创建账本。流水、模板和分类可按账本管理，资金账户在各账本间共用；移动流水不会再扣款，归档账本只供查询。
3. 使用中间记账按钮录入支出、收入、转账或债务。分类、标签、备注、日期、附件和四则金额键盘在同一流程中使用；“再记”保存后继续下一笔。
4. 在“资产 → ＋”建立证券、加密交易所或钱包。录入已有持仓不扣资金账户；新买入才记录实际支付。成本不清楚可留空，未知成本不会按零计算盈利。

## 资产入口

| 入口 | 操作与口径 |
|---|---|
| 资产首页 | 净资产、资产/负债、报销/债务/理财摘要、分组折叠、金额隐藏、账户排序与隐藏 |
| 新建/编辑账户 | 资金、信贷、预付卡、保险、房产/车辆、自定义、债务、报销及投资账户；简称、备注、卡号、图标、分组、生效账本和计入总资产 |
| 资金账户详情 | 记账、转账、余额校准、余额变动、资产明细、转账记录、流水对账、CSV 导出、定期存款及编辑/删除 |
| 收益同步 | 从人民币资金账户编辑页进入；只填基金名称、代码、开始计息时间，名称/代码均可搜索；解绑保留历史收益 |
| 报销 | 创建报销账户，记支出时选择报销对象；在待报账单记录一次或多次到账，可结束/恢复或取消报销 |
| 债务 | 追加借入/借出、分次还款/收回、利息/优惠、还款日期、方向转换和结清隐藏；本金不重复计入收支 |
| 信用卡 | 额度/共享额度、账单日、还款规则、年费条件、各期账单、还款记录及分期管理 |
| 定期存款 | 记录已在账户内的本金、利率、期限、开始日期，查看预计收益、到期结算或提前结束 |
| 投资与加密账户 | 股票、基金、加密资产和其他持仓；买入、卖出、币币兑换、账户转移、历史修订及撤销 |

长按账户或使用详情菜单可删除。先查看关联记录预览，再选择处理关联交易或确认级联删除。转账双边、投资事实和其他账户余额会一起校验、更新；剩余投资历史不成立时整次取消。系统结算账户不能删除。

余额校准保留差额流水，可选是否计入收支。房产、车辆、保险、预付卡沿用账户余额，不提供市场自动估价。信用卡分期不重复增加本金负债；费用按计划独立入账，实际还款须另行记录。

货币基金仅对显式绑定的账户生成收益，按账内交易和起息规则计算；这不等于银行或基金平台实际结算。定存本金不再次增加资产，并从其有效期内的货币基金计息本金扣除。普通证券/加密行情只改变参考估值。

## 日历、统计与提醒

日历按用户时区、每周起始日显示收支、农历/节气、手动事项和到期安排；选中日期可直接记账。事项自身不改余额。统计支持账本/日期筛选、收支趋势、分类占比与排名、分类及日期下钻，内部转账和投资结算不混入生活收支。

资产提醒可组合信用卡、借款日期、手动事项及定存到期。Android 通知需要系统授权；应用被停止期间不保证持续计算，重新打开时补齐可结算记录。

## 行情与未知值

搜索后核对市场、代码、来源和币种再绑定。同名资产不自动合并；手动人民币价格优先。证券、基金、加密报价和人民币汇率保留各自日期与状态，缺失值不按零处理，报价过期会明确标记。

自动换算只供录入参考，实际支付/到账由用户确认。没有有效行情时仍可填写实际成交；缺少历史换算依据的成本和盈亏保持未知。供应商、刷新规则、可选密钥及联网检查见 [行情模块](pkg/marketquotes/README.md)。

## 本机开发

现有工具：Go `D:\tools\cyledger\go\bin`、GCC `D:\tools\cyledger\mingw64\bin`，启动脚本会将它们加入当前进程 PATH；需要 Node.js/npm 和 Python。Android 工具路径与构建命令见 [Android 说明](android/README.md)。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-CYLedger.ps1 -Build -DirectNpm
```

浏览器打开 [http://localhost:8080/mobile](http://localhost:8080/mobile)。`-DirectNpm` 使用独立 npm 配置，不修改全局代理。正式运行数据在 `.runtime/data`、附件在 `.runtime/storage`；签名配置、已有本机登录说明和 Android 签名材料均为私密文件，不提交仓库。

按改动范围执行必要检查：

```powershell
go test ./pkg/investments ./pkg/monetaryincome ./pkg/marketquotes ./pkg/services ./pkg/models ./pkg/api ./android/backend
npx vue-tsc --noEmit
npx vitest run
npm run build
python -m unittest discover -s scripts -p test_backup.py -v
```

涉及手机流程时，还需独立 QA 包的真机验收和同签名正式版覆盖升级。已执行的检查与没有覆盖的部分统一记录在 [验收与交接](docs/CYLEDGER_ACCEPTANCE.md)，不以编译通过代替账务或真机验证。
